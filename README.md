# 副業タイプ診断「はじめの一歩」

> 「向いてる副業」より、「明日やること」がわかる診断ツール。

全16問・約3分で8タイプのうちどれかを判定し、そのまま**最初の7日間の行動プラン**まで出します。
登録・メールアドレス入力は不要です。

## 特徴

- **登録なし・無料** — メールアドレスも要りません
- **8タイプ判定** — 「稼ぎ方 × 得意技 × 出し方」の3軸で分類
- **7日間プランつき** — Day1から何をするかまで出ます
- **サーバーなし** — 回答データは送信されず、ブラウザ内にのみ保存されます

## 技術構成

HTML / CSS / JavaScript のみの1ファイル構成です。ビルド不要、依存ライブラリなし。

```
index.html    アプリ本体
.nojekyll     GitHub Pages の Jekyll 処理を無効化
```

## ローカルで動かす

ファイルを開くだけで動きます。

```bash
open index.html
```

## 注意事項

- 結果に記載している金額・期間はすべて**目安**であり、成果を保証するものではありません
- お勤めの方は、勤務先の就業規則をご確認のうえでご利用ください
